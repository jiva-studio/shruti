La pestaña **Inicio** es tu lista — las clases que estás escuchando, bajo el
encabezado **A continuación**. Funciona completamente sin conexión.

## Añadir clases

- Desde **Buscar**, abre una clase y toca **Añadir a la lista**.
- Desde una respuesta de **Pregúntale a Sadhu**, mantén pulsada una cita y
  añade la clase completa.

Todo lo que añades se descarga para escuchar sin conexión automáticamente —
esto es gratis y no necesita suscripción. Cuando no has iniciado sesión, la
app te ofrece de inicio unas cuantas clases destacadas para que la lista nunca
esté vacía.

## Reproducir y progreso

- **Toca una pista** para reproducirla; se reanuda donde la dejaste.
- El **anillo** alrededor de una pista muestra tu posición guardada, y se va
  llenando en tiempo real para la pista que se está reproduciendo.
- Una **doble marca** señala una clase que terminaste de principio a fin.
- Una colección añadida como conjunto muestra un único anillo para todo el
  grupo — el progreso promedio de sus clases.

## Gestionar la lista

- **Quita** una clase deslizando su fila y tocando eliminar. Se archiva, no se
  borra — puedes encontrarla y volver a añadirla desde Buscar.
- Las clases se mantienen en el **orden en que las añadiste**; no hay
  reordenamiento manual.

## Reproducción continua (PRO)

Activa la **Reproducción automática** (Ajustes → Apariencia) y la siguiente
clase de la lista empieza automáticamente cuando una termina, incluso con la
pantalla bloqueada. Esto forma parte de la suscripción PRO. Sin ella, la
reproducción se detiene al final de cada clase.
