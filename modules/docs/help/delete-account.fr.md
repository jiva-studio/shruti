Dans **Paramètres**, appuyez sur la ligne de votre compte et choisissez
**Supprimer le compte**. L'application vous demande alors quoi faire des
données présentes sur cet appareil.

## Ce qui se passe

- Sur nos serveurs, nous supprimons immédiatement : votre e-mail, les
  liens vers Google et Apple, ainsi que les traces de diagnostic de vos
  requêtes de chat.
- Sur l'appareil, vous choisissez l'une des deux options :
  - **Supprimer le compte et effacer les données** — l'application revient
    à un état vierge : votre playlist, vos notes, l'audio téléchargé et
    l'historique de chat sur ce téléphone sont effacés.
  - **Supprimer le compte, conserver mes données** — tout ce qui est local
    reste en place et l'application continue de fonctionner en mode
    anonyme.

Dans les deux cas, vous êtes déconnecté. Vous pouvez vous reconnecter
avec le même compte Google ou Apple, mais de notre côté ce sera un
nouveau compte.

## Ce qui ne peut pas être supprimé

Les messages que vous avez déjà envoyés via le chat passent par un
fournisseur de LLM externe (OpenRouter / Google Gemini). Ces services les
conservent selon leurs propres règles — généralement jusqu'à 30 jours à
des fins de protection contre les abus. Nous n'avons aucun accès à leur
stockage.

Les enregistrements d'achat d'abonnement restent chez Apple ou Google —
nous ne pouvons pas non plus les supprimer.

Pour tous les détails, consultez la [politique de
confidentialité](https://akdasa-studios.github.io/shruti/).
