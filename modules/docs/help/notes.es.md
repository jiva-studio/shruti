Las **Notas** te permiten guardar pasajes de las clases — una frase, un
párrafo o un fragmento más largo — para que puedas volver a ellos más tarde,
compartirlos o escuchar de nuevo solo ese fragmento.

## Crear una nota

- Abre la **transcripción** de una clase (toca el cuerpo del reproductor
  mientras se está reproduciendo).
- **Selecciona un rango de texto** manteniendo pulsada una frase y arrastrando
  los tiradores para abarcar el pasaje que quieras.
- Toca **Guardar como nota**. La nota recuerda tanto el texto como el rango de
  audio, así puedes volver a reproducir el fragmento exacto más tarde.
- También puedes guardar una nota desde una **cita del chat**, manteniendo
  pulsada una cita en una respuesta de Pregúntale a Sadhu.

## La pestaña Notas

La pestaña Notas enumera cada fragmento guardado con su clase de origen. Desde
aquí puedes:

- **Tocar una nota** para abrir el reproductor de audio integrado y escuchar
  solo ese fragmento.
- **Buscar** notas escribiendo en el cuadro de arriba.
- **Compartir** una nota como texto o como clip de audio — mantén pulsado para
  abrir la hoja de acciones.
- **Eliminar** una nota cuando ya no la necesites.

Con una suscripción PRO, el **Estudio** también puede convertir una nota en un
vídeo corto para compartir — mantén pulsada una nota y elige **Abrir en el
Estudio**.

## Privacidad

Las notas se guardan localmente en tu dispositivo y se sincronizan como parte
de tus datos personales. Nunca aparecen en resultados de búsqueda visibles
para otros usuarios, y se incluyen en la **Exportación** para que puedas
llevarlas de un dispositivo a otro.
