La mayoría de las clases del catálogo vienen con una **transcripción
sincronizada** — el texto de la clase alineado con el audio para que puedas
leer al mismo tiempo y saltar entre frases con un solo toque.

## Abrir la transcripción

Cuando una clase se está reproduciendo, **toca el cuerpo del reproductor**
(en cualquier punto excepto el botón de reproducción) para abrir la
transcripción; toca de nuevo para cerrarla sin detener la reproducción. La
transcripción también se puede configurar para que **se abra automáticamente**
cuando empieza la reproducción (Ajustes → Apariencia).

## Qué puedes hacer

- **Tocar una frase** para saltar la reproducción del audio a ese momento
  exacto.
- **Seguir la lectura** — la frase actual se resalta a medida que suena el
  audio (interruptor en Ajustes → Apariencia). Con el **Desplazamiento
  automático** PRO activado, la transcripción también se desplaza sola para
  que la línea activa quede a la vista.
- **Seleccionar un fragmento** para guardarlo como **nota** o compartirlo como
  cita. Las notas recuerdan el rango de audio, así puedes volver a reproducir
  solo ese fragmento más tarde desde la pestaña Notas.
- **Cambiar de idioma** en clases multilingües usando el selector de idioma en
  la parte superior de la transcripción.

## Calidad

Las transcripciones se producen a partir del audio original y se revisan para
asegurar su exactitud. Cuando la puntuación o la atribución del hablante
parezca incorrecta, el audio en sí es siempre la fuente de verdad — toca la
frase para oírla hablada.
