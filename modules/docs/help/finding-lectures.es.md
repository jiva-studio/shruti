La pestaña **Buscar** es donde descubres clases y las añades a tu lista. Es un
explorador del catálogo, no un cuadro de preguntas — para hacer una pregunta
con tus propias palabras y obtener una respuesta, usa **Pregúntale a Sadhu**.

## Formas de encontrar una clase

- **Cuadro de búsqueda.** Escribe unas palabras del título o del tema. Los
  resultados salen del catálogo y se limitan a los idiomas de clase que hayas
  elegido (Ajustes → Biblioteca).
- **Recomendado para ti.** Una estantería de clases escogidas a partir de lo
  que has escuchado.
- **Colecciones.** Conjuntos curados de clases agrupados por tema, serie o
  evento. Toca una colección para abrirla; toca **Ver todo** en un grupo para
  explorar todas las colecciones que contiene.
- **Tópicos.** Mosaicos de tópicos (mostrados como `#hashtags`). Toca uno para
  ver todas las clases sobre ese tópico. Más abajo también aparecen estanterías
  de tus tópicos más escuchados.
- **Todas las clases.** El catálogo completo como una lista plana, accesible
  desde la sección **Clases**.

## Filtros

Abre el filtro para acotar cualquier lista. Puedes combinar:

- **Autores, lugares, fuentes, temas, tópicos, idiomas** — elige uno o varios
  de cada uno.
- **Duración** — hasta 15 minutos, 15-30, 30-60 o más de 60 minutos.
- **Fechas** — un rango desde/hasta.
- **Orden** — más recientes primero, más antiguas primero o por referencia
  escritural.

El mismo filtro alimenta la reserva de la Biblioteca inteligente (Ajustes →
Sādhana).

## Añadir una clase

Toca una clase para abrir sus acciones y luego **Añadir a la lista**. La clase
aparece en tu lista de Inicio y empieza a descargarse para escuchar sin
conexión de inmediato — sin necesidad de suscripción. Una pista que ya está en
tu lista muestra una marca verde; una terminada muestra una doble marca.
Consulta la página *Indicadores de pista* para saber qué significa cada
insignia.
