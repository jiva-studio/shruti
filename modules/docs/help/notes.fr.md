Les **notes** vous permettent d'enregistrer des passages de conférences —
une phrase, un paragraphe ou un extrait plus long — afin d'y revenir plus
tard, de les partager ou de réécouter ce seul fragment.

## Créer une note

- Ouvrez la **transcription** d'une conférence (appuyez sur le corps du
  lecteur pendant la lecture).
- **Sélectionnez une plage de texte** en appuyant longuement sur une
  phrase et en faisant glisser les poignées pour couvrir le passage
  souhaité.
- Appuyez sur **Enregistrer comme note**. La note mémorise à la fois le
  texte et la plage audio, pour que vous puissiez rejouer l'extrait exact
  plus tard.
- Vous pouvez aussi enregistrer une note à partir d'une **citation du
  chat** en appuyant longuement sur une citation dans une réponse de
  Demandez à Sadhu.

## L'onglet Notes

L'onglet Notes liste chaque extrait enregistré avec la conférence dont il
provient. De là, vous pouvez :

- **Appuyer sur une note** pour ouvrir le lecteur audio intégré et écouter
  ce seul fragment.
- **Rechercher** dans les notes en tapant dans la barre du haut.
- **Partager** une note sous forme de texte ou de clip audio — appuyez
  longuement pour ouvrir la feuille d'actions.
- **Supprimer** une note dont vous n'avez plus besoin.

Avec un abonnement PRO, le **Studio** peut aussi transformer une note en
courte vidéo à partager — appuyez longuement sur une note et choisissez
**Ouvrir dans le Studio**.

## Confidentialité

Les notes sont stockées localement sur votre appareil et synchronisées
dans le cadre de vos données personnelles. Elles n'apparaissent jamais
dans les résultats de recherche visibles par d'autres utilisateurs, et
elles sont incluses dans l'**Export** pour que vous puissiez les
transférer d'un appareil à un autre.
