# Settings overview

The Settings screen is grouped by purpose. Here is what every group and item
controls.

## Account

- **Sign in** — log in with Google (and Apple on iOS) to keep your library,
  notes and listening progress in sync when you switch devices. Tap the row
  again while signed in to sign out.
- **Subscription** — your "Shruti" Pro subscription. Tap it to open
  the paywall when you are not subscribed, or to manage / cancel it via the
  store when you are.
- **Server** — which content-delivery network the app downloads from. Pick a
  closer region if downloads feel slow.

## Appearance

- **Language** — language of the app interface (English / Russian). Changing
  it switches all labels, but does not affect the language of lectures
  themselves.
- **Player progress** — show or hide the progress ring around the play button
  in the floating mini-player.
- **Notes tab** — show or hide the Notes tab in the bottom navigation. Hidden
  by default for users who do not use notes.
- **Highlight sentence** — while a transcript is open during playback, the
  current spoken sentence is highlighted. Turn off if you find it
  distracting.
- **Open transcript automatically** — when you start a lecture, the
  transcript view opens automatically if available.

## Sadhana

- **Activity tracker** — show the listening heatmap on the home screen.
- **Notifications** — enable the daily reminder.
- **Reminder time** — the time of day the reminder fires. Visible only when
  notifications are on.

See the *Activity tracker* and *Notifications and reminders* help pages for
the details.

## Data

- **Export user data** — save a backup file containing your playlist, notes,
  downloads and listening progress.
- **Import user data** — restore from a previously exported file. This
  **replaces** the data currently in the app.

See the *Export and import* help page.

## About / version

At the bottom of the screen you can see the app version, build identifier
and the content database number. This information is useful when reporting a
problem.
