As **Notas** permitem salvar passagens das aulas — uma frase, um parágrafo ou um
trecho mais longo — para você voltar a elas depois, compartilhá-las ou ouvir só
aquele fragmento de novo.

## Criando uma nota

- Abra a **transcrição** de uma aula (toque no corpo do player enquanto ela está
  tocando).
- **Selecione um trecho de texto** mantendo pressionada uma frase e arrastando as
  alças para cobrir a passagem que você quer.
- Toque em **Salvar como nota**. A nota guarda tanto o texto quanto o trecho de
  áudio, então você pode reproduzir o exato fragmento mais tarde.
- Você também pode salvar uma nota a partir de uma **citação do chat**, mantendo
  pressionado um trecho em uma resposta do Pergunte ao Sadhu.

## A aba Notas

A aba Notas lista cada trecho salvo com a aula de origem. A partir daqui você
pode:

- **Tocar em uma nota** para abrir o player de áudio embutido e ouvir só aquele
  fragmento.
- **Buscar** notas digitando na caixa do topo.
- **Compartilhar** uma nota como texto ou como um clipe de áudio — mantenha
  pressionado para abrir a folha de ações.
- **Excluir** uma nota quando você não precisar mais dela.

Com uma assinatura PRO, o **Estúdio** também pode transformar uma nota em um vídeo
curto para compartilhar — mantenha pressionada uma nota e escolha **Abrir no
Estúdio**.

## Privacidade

As notas são armazenadas localmente no seu aparelho e sincronizadas como parte dos
seus dados pessoais. Elas nunca aparecem em resultados de busca visíveis a outros
usuários, e são incluídas na **Exportação** para você poder levá-las entre
aparelhos.
