# Activity tracker

The activity tracker on the home screen turns your listening into a visible
pattern. It can be hidden in **Settings → Sadhana → Activity tracker** if you
do not want it on the home screen.

## Heatmap

Each square is one day. The darker the square, the more you listened.
Thresholds are fixed:

| Color depth | Time listened that day |
| ----------- | ---------------------- |
| Empty       | None                   |
| Light       | Less than 15 minutes   |
| Medium      | 15 minutes to 1 hour   |
| Strong      | 1 hour to 2 hours      |
| Deepest     | 2 hours or more        |

Today's square has a colored border so you can spot it quickly.

## Day streak

The flame badge counts consecutive days with any listening — even a few
minutes is enough. The streak resets the moment a full calendar day goes by
without a session.

## Completed lectures

The rosette badge counts lectures you listened to from beginning to end. A
lecture is marked completed only when playback actually reaches the final
moment, not when you tap somewhere near it.

## Total listening time

The clock badge shows the cumulative time spent in the player across all
sessions. Pausing, scrubbing or playing the same lecture again does not
inflate the number — only real playback adds to it.

## Where the data lives

All of this is stored on the device. Nothing is uploaded to a server, and
nothing is shared with other accounts. If you reinstall the app or clear user
data, the heatmap starts empty.
