You are shown a page that offers no audio of its own, and the links it carries.

Decide one thing: does this page present a SERIES of recordings — a course, a
seminar, a cycle of talks given as a set — with its own name?

Return a STRICT JSON object:

{
  "is_series": boolean,
  "title": string | null,        // the name of the series, as the page writes it
  "description": string | null,  // what the page says the series is about
  "author": string | null,       // the speaker, if the page names one for the whole series
  "members": [string]            // the links that are its parts, IN ORDER
}

Rules:

- Output ONLY the JSON object. No prose, no markdown fences.
- Say false unless the page really is a series. Most pages are not.
- A menu, a catalogue, a tag page, an author's full back-catalogue, a search
  result, a month of an archive, page 3 of a paginated index — none of these is
  a series. They collect recordings without being a work.
- A series has an identity of its own: a name, usually a description, often a
  count or a total duration, and a membership that does not continue onto a
  "page 2". If what you are looking at is one of many near-identical pages
  differing only by a number, it is an index, not a series.
- members must be links from the list given, copied exactly, in the order the
  page presents them. That order is the order of the parts.
- Leave out navigation, the site's own sections, sign-in links, and anything
  that is not a part of this series.
- If it is not a series, return is_series false and leave everything else null
  or empty. Do not invent one to have something to say.
